Situation 1

The URL Parameter Vulnerability

A university student discovers that another student can access their grades and personal demographic profile simply by incrementing or changing a number in the website's URL (e.g. view_profile.php?id=1042).

View Guided Questions & Model Solution ➕

Q1: What security vulnerability exists?
Answer: Broken Object Level Authorization (BOLA) or Insecure Direct Object Reference (IDOR), combined with insufficient access control checks.

Q2: Which CIA principle is affected?
Answer: Confidentiality, because sensitive personal data is disclosed to unauthorized viewers.

Q3: What security control would you recommend?
Answer: Server-side validation enforcing that the session user token matches the requested resource ID, combined with indirect reference maps (UUIDs) and RBAC authorization middleware.

Situation 2

The First Day Enrollment Outage

A university's enrollment website becomes completely unavailable during the first day of class registration because of excessive illegitimate traffic flood generated by external attackers.

View Guided Questions & Model Solution ➕

Q1: What type of attack is occurring?
Answer: Denial-of-Service (DoS) or Distributed Denial-of-Service (DDoS) attack.

Q2: Which CIA principle is affected?
Answer: Availability, because authorized students cannot access the registration service.

Q3: What security controls could prevent or reduce this incident?
Answer: Cloud DDoS scrubbing (Cloudflare / AWS Shield), reverse proxy load balancers, rate limiting on HTTP requests, and dynamic auto-scaling web application clusters.

Situation 3

The Rogue Employee & Wiped Logs

An employee alters student grades without authorization and subsequently deletes the local system activity logs to hide the illicit activity.

View Guided Questions & Model Solution ➕

Q1: What two security principles are affected?
Answer: Integrity (unauthorized alteration of grade records) and Availability / Accountability / Non-Repudiation (erasure of audit trails).

Q2: Which STRIDE categories are involved?
Answer: Tampering (altering records and modifying log files) and Repudiation (deleting evidence so the employee can deny the action).

Q3: What security controls could prevent or detect this activity?
Answer: Separation of duties, centralized write-once immutable logging (WORM / SIEM) shipped in real time to an isolated server where even admins cannot delete records, and cryptographic file integrity monitoring (FIM).
